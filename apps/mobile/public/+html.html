This file is a kept record of the first PWA attempt, preserved in place rather than deleted. It rested on a wrong premise: this app does not use expo-router (there is no expo-router dependency; the entry is the plain App.tsx), so the expo-router/html +html convention never applies here. As a file inside public/ it is only copied verbatim into the web export as a static asset; nothing renders it as a template. The real template hook for this stack is public/index.html — the Expo CLI checks the public folder for index.html before falling back to its bundled template — and that is where the manifest link, theme-color and touch icon live. This file is inert; its original content is kept in the comment below.

# Mascot assets

## Arthur (default)

`arthur.png` is the default asset rendered by the shared `Mascot` component: Arthur's face (nerdy character with round glasses), cropped circular from Arthur's current-look artwork on November 13, 2026. It is a 1254×1254 RGBA PNG with a transparent background outside the circular crop, matching the dimensions of the previous default. Sky, sand and lilac backgrounds preserve the avatar color preference. Pass a different `source` to the `Mascot` component to swap in another character.

## OpenMuse capybara

`capybara.png` is original artwork generated for OpenMuse with the built-in image-generation tool on September 16, 2026. The transparent PNG is bundled locally and remains available as a `Mascot` source for customization. The asset is included under this repository's MIT license.

Sitting in a gentle three-quarter view, with warm caramel and oat tan coloring, a calm expression, a soft clay/plush finish and restrained detail readable at 48–96 pixels. Entire character centered on a transparent background. One character, no clothing, props, text, logos or watermark.”
